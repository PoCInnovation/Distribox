# Lab configurations

The **Provision a VM** page and the **New event** dialog open with a **Start from**
row when you can see past events. It suggests the four newest distinct
configurations, labelled with the event they come from.

There is no separate save step or template list. Every event you create keeps its
image, size, keyboard layout and SSH setting, and that event becomes a suggestion.
Events with the same configuration appear once.

Choosing a suggestion fills the image, vCPU, memory, disk, keyboard layout and SSH
fields. You can change any of them before you create the VM or event. The name,
join link, deadline and seat count stay as you set them, so a new event gets its
own slug and deadline. Participants and credentials are never copied.

Editing an existing event shows no suggestions.
