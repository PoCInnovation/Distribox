# Lab configurations

Past events are the saved lab configurations. There is no separate save step or
template list: every event keeps its image, size, keyboard layout, SSH setting and
seat count.

To repeat a lab, click **Run again** on an event. The button shows on ended events
in the Events list and on every event page, and the event's menu has it too. It
opens **New event** with that event's setup already filled in.

**New event** and **Provision a VM** also have a **Copy from** menu next to the
title. It lists the five newest events and fills the form from the one you pick.
A new VM takes the image, size, keyboard layout and SSH setting; a new event also
takes the seat count.

Every field stays editable before you create. The name, join link and deadline
are never copied, so a new event always gets its own slug and deadline.
Participants and credentials are never copied either.
